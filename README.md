## ✨ About Me

I'm a data analytics student with a Computer Science background (+2 Science), currently sharpening my skills in data analysis, visualization, and applied machine learning. I care about following a question all the way from raw data to an honest, useful answer — not just producing a chart.

Right now I'm building a **Retrieval-Augmented Generation (RAG) learning path** one project at a time — starting from manual semantic search, moving through vector databases with ChromaDB, and now working toward multi-format document ingestion. I'm also the author of an independent research study on career readiness among SEE and +2 graduates in Nepal, built on a survey I designed and distributed myself.
